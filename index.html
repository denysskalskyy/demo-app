Help & Documentation

Quick Start Guide

Welcome to the Forex Analytics Dashboard! This interactive proof-of-concept application is designed to analyze CAD vs. USD exchange rates (FRED DEXCAUS format).

Step 1

Open App

Simply run index.html in any modern web browser or open it through GitHub Pages.

Step 2

Configure Filters

Select standard start/end dates and choose from Daily, Weekly, Monthly, or Quarterly aggregations.

Step 3

Analyze Data

Hover over the bar chart for tooltips, and browse the rate table containing inverted calculations.

Restoring Defaults

If you ever change dates and want to restore the dashboard to its original view, click the "Reset to Last Week" button. This instantly resets the calendar to the last active 5 weekdays: 2026-08-10 to 2026-08-14.

User Manual

This manual provides step-by-step instructions on utilizing the features of the Forex Analytics Dashboard.

1. Period Filter Panel

The controls panel at the top of the interface governs the active historical dataset range:

  • Start Date / End Date: Sets the boundaries for target analysis. The historical dataset stretches from 2026-07-01 to 2026-08-14.
  • Aggregation Selection: Choose how to bucket and analyze chart rates:
    • Daily: Plots individual daily spot transaction rates.
    • Weekly Average: Groups active dates into weekly buckets, calculating the average rate.
    • Monthly Average: Groups records by calendar month to calculate monthly averages.
    • Quarterly Average: Groups records by calendar quarter to calculate quarterly averages.
  • Apply Filter Button: Reprocesses the chart metrics and rebuilds the detailed spot rate grid instantly.

2. Interactive Bar Chart

An interactive representation of spot rates within your filtered window:

  • Flexible Legends: The chart labels and legends automatically adjust to indicate the selected aggregation mode (e.g., Daily Rate, Weekly Average, Monthly Average).
  • Tooltips: Hovering cursor over any individual bar provides precise popovers showing the bucket label and corresponding spot rate value in CAD.

3. Detailed Data Table

A highly structured record ledger featuring on-the-fly math:

  • Inverted Rates: Evaluates and renders `1 / rate` representing USD per 1 CAD on-the-fly, rounded to 4 decimal places.
  • Market Status Indicators: Dynamically maps each calendar day:
    • Market Open (Green Badge): Active weekdays with transaction rates.
    • Market Closed (Gray Badge): Weekends or holidays with no trading.

Frequently Asked Questions (FAQ)

Q1: Why does the dashboard crash and show a big red alert banner?

A: This is an intentional data-parsing bug built directly into our sandbox to demonstrate client-side exception interception:

  • The rates database maps weekends and market holidays to "ND" (No Data).
  • If your filters include a weekend date, the data processing pipeline runs an unchecked parseFloat("ND").
  • This yields NaN, throwing a critical unhandled TypeError that triggers the red exception banner.

Q2: How do I recover from a critical database parse crash?

A: Simply click the "Reset to Last Week" button. This instantly resets the calendar filters to active weekdays (avoiding weekends) and restores the dashboard's operational state.

Q3: Why do weekend records show "Market Closed"?

A: Weekend dates do not have active currency trading. They are mapped in our database with a rate value of "ND" and displayed with a gray "Market Closed" status badge.

Q4: How is the inverted calculation computed?

A: The database stores rates as CAD per 1 USD. The table computes 1 / rate to display the inverse value representing USD per 1 CAD, rounded to 4 decimal places.
